## API Reference
- [List Customers](https://developer.moneris.com/moneris-api/reference/getcustomers.md): Returns a paginated list of customers.
- [Create Customer](https://developer.moneris.com/moneris-api/reference/createcustomers.md): This operation is used to created a new customer.
- [Retrieve Customer](https://developer.moneris.com/moneris-api/reference/getcustomer.md): Retrieve a customer by their Id.
- [Update Customer](https://developer.moneris.com/moneris-api/reference/updatecustomer.md): Updates customer's details such as name, address etc...
- [Delete Customer](https://developer.moneris.com/moneris-api/reference/deletecustomer.md): Delete a customer by their Id
- [Create Merchant](https://developer.moneris.com/moneris-api/reference/createmerchant.md): Submit a merchant payload to create a merchant
- [Get the details of a Merchant](https://developer.moneris.com/moneris-api/reference/getmerchantdetailsbymerchantid.md): Get merchant details by ID
- [Update Merchant](https://developer.moneris.com/moneris-api/reference/updatemerchant.md): Update merchant based on the supplied payload.
- [List merchant supplies](https://developer.moneris.com/moneris-api/reference/listmerchantsupplies.md): Get merchant supplies by merchant ID
- [Multi-Currency Pricing Rate Lookup](https://developer.moneris.com/moneris-api/reference/mcprate.md): Performs a foreign currency exchange rate look-up, and secures that exchange rate for use in a subsequent Multi-Currency Pricing financial transaction.  The exchange rate retrieved by this transaction request is represented in the response as the multiCurrencyPricingRateLookupId, and the underlying exchange rate is locked in for a limited time period.
- [Retrieve Multi-Currency Pricing Rate by Id.](https://developer.moneris.com/moneris-api/reference/getmulticurrencypricingratebyid.md): Retrieve Multi-Currency Pricing Rate results by Id.
- [Accept Dispute](https://developer.moneris.com/moneris-api/reference/acceptdispute.md): If no longer want to dispute a chargeback or copy request.
- [Dispute Details](https://developer.moneris.com/moneris-api/reference/getdisputebycaseidandrecordnumber.md): To determine whether you can upload documents for a specific case.
- [Upload Images](https://developer.moneris.com/moneris-api/reference/uploaddisputeimage.md): To upload response documents associated with a disputed transaction.
- [Check image upload status](https://developer.moneris.com/moneris-api/reference/getdisputeuploadstatus.md): This endpoint can be used to check image upload status
- [Installment Plan Lookup](https://developer.moneris.com/moneris-api/reference/installmentlookup.md): Returns list of installment plans the cardholder is eligible for.
- [List Recommended Products](https://developer.moneris.com/moneris-api/reference/getrecommenderproducts.md): Get recommender products to fetch multiple items related to a client
- [List Payments](https://developer.moneris.com/moneris-api/reference/getpayments.md): Returns a paginated list of payments.
- [Create Payment](https://developer.moneris.com/moneris-api/reference/createpayments.md): This operation is used to initiate a Payment.
- [Retrieve Payment](https://developer.moneris.com/moneris-api/reference/getpayment.md): Retrieve a payment by its payment Id
- [Cancel Payment](https://developer.moneris.com/moneris-api/reference/cancelpayment.md): Cancel a payment. This operation may not be possible if the payment has gone through.
- [Complete Payment](https://developer.moneris.com/moneris-api/reference/completepayment.md): This will effectively capture a payment that has been authorized.
- [Increment Payment](https://developer.moneris.com/moneris-api/reference/incrementpayment.md): Increases the locked amount of funds in an existing pre-authorization (Payment with automaticCapture = false) for later settle by a single pre-authorization completion.  There is no limit to the number of Increment Payment API calls on the original estimated authorization and each new Increment Payment increases the hold on the customer's credit card.
- [List payment methods](https://developer.moneris.com/moneris-api/reference/getpaymentmethods.md): Retrieves a paginated list of payment methods.
- [Create Payment Method](https://developer.moneris.com/moneris-api/reference/createpaymentmethod.md): Create a Payment Method.
- [Retrieve Payment Method](https://developer.moneris.com/moneris-api/reference/getpaymentmethod.md): Retrieve a Payment Method by Id
- [Update Payment method](https://developer.moneris.com/moneris-api/reference/updatepaymentmethod.md): Update payment method referenced by its Id.  Certain details may not be updated if the payment method was used in a transaction.
- [Delete Payment Method](https://developer.moneris.com/moneris-api/reference/deletepaymentmethod.md): Deletes a payment method.
- [Create Kount Inquiry](https://developer.moneris.com/moneris-api/reference/createkountinquiry.md)
- [List Kount Inquiries](https://developer.moneris.com/moneris-api/reference/getkountinquiries.md)
- [Get Kount Inquiry by Id](https://developer.moneris.com/moneris-api/reference/getkountinquirybyid.md)
- [Kount Inquiry Assert](https://developer.moneris.com/moneris-api/reference/kountinquiryassert.md)
- [List Refunds](https://developer.moneris.com/moneris-api/reference/getrefunds.md): Returns a paginated list of refund operations.
- [Create Refund](https://developer.moneris.com/moneris-api/reference/createrefund.md): This operation is used to create a Refund.  For payment refunds, Payment Id is required while payment method is not required. For independent refunds, no payment Id is required, however payment method is required.
- [Retrieve Refund](https://developer.moneris.com/moneris-api/reference/getrefundbyid.md): Retrieve a refund by its Id.

- [Retrieve Subscription](https://developer.moneris.com/moneris-api/reference/getsubscription.md): Retrieve a Subscription details by Id
- [Update Subscription](https://developer.moneris.com/moneris-api/reference/updatesubscription.md): Update Subscription
- [Resume Subscription](https://developer.moneris.com/moneris-api/reference/resumesubscription.md): Resumes a subscription billing. While a transaction is on hold, it is not billed for the subscription amount.                  However, the number of remaining recurs continues to be decremented during that time.
- [Pause Subscription](https://developer.moneris.com/moneris-api/reference/pausesubscription.md): Temporarily pauses subscription billing. While a transaction is on hold, it is not billed for the subscription amount.                  However, the number of remaining recurs continues to be decremented during that time.
- [Cancel Subscription](https://developer.moneris.com/moneris-api/reference/cancelsubscription.md): Cancel a Subscription.
- [Extend Subscription](https://developer.moneris.com/moneris-api/reference/extendsubscription.md): Adds the given number of subscription transactions to the current (remaining) number.  This can be used if a customer decides to extend a membership/subscription.  However, because this must be a positive number, it cannot be used to decrease the current number of subscription transactions.  For that, use Update Subscription.
- [Create Authentication](https://developer.moneris.com/moneris-api/reference/createauthentication.md): This operation is used to create an Authentication request.  The authentication request is used to start the validation process of the card.  The result of this request determines whether 3DS is supported by the card and what type of authentication is required.
- [Retrieve Authentication](https://developer.moneris.com/moneris-api/reference/getauthentication.md): Retrieve an authentication by its authentication Id
- [Authentication Value Lookup](https://developer.moneris.com/moneris-api/reference/authenticationvaluelookup.md): The point of the 3-D Secure flow is to verify that the true cardholder is a part of the authorization. The challenge flow is used to present a way of authenticating the cardholder using e.g. OTP or a federated identification method.
- [3DS Card Lookup](https://developer.moneris.com/moneris-api/reference/cardlookup.md)
- [List Card Validations](https://developer.moneris.com/moneris-api/reference/getvalidations.md): Returns a paginated list of the card validations the were executed.
- [Create Card Validation](https://developer.moneris.com/moneris-api/reference/createvalidation.md): Initiate a new Card Validation request.
- [Retrieve Card Validation.](https://developer.moneris.com/moneris-api/reference/getvalidation.md): Retrieve a Card Validation by Id.
- [Surcharge Lookup](https://developer.moneris.com/moneris-api/reference/surchargelookup.md): Performs surcharge lookup and determines if payment method is eligible or not and provides max rate and max amount if eligible.
- [Create Order](https://developer.moneris.com/moneris-api/reference/createorder.md): Submit an order payload to create an order for the merchant
- [Retrieve order by Id](https://developer.moneris.com/moneris-api/reference/getorderdetailsbyorderid.md): Get order details by ID
- [Update an order by ID](https://developer.moneris.com/moneris-api/reference/updateorder.md)
